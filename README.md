# Contact Book (Python + SQLite)

A command-line contact book that stores contacts in a SQLite database.

## Features
- Add, view, search, update and delete contacts
- Phone number validation
- Data saved permanently in a SQLite database
- Parameterized SQL queries

## How to run
1. Install Python 3
2. Download contact_book.py
3. Run: python contact_book.py

## Built with
Python, SQLite (sqlite3 module)
